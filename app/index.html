Overview

Vehicle conditions and display options

Freshness uses the observed interval for each signal in this capture; it is not a sensor-health verdict. Green appears only for a sourced range with confirmed test conditions. Gray means no sample, stale, hidden, unsupported or not applicable; the text explains which.

Recording and export

Recordings remain on this device. Interrupted sessions remain incomplete; saving does not certify diagnostic validity.

Faults and self-tests

Choose one request for this read. The app will not try the other mode automatically. Decoded response bytes are not ECU verified unless the bridge explicitly reports that verification.

    Failure-memory flags · technical detail

    The app preserves both bytes and shows bit positions. Per-bit meanings are not verified for this ECU calibration; a set bit is not automatically a confirmed component fault.
