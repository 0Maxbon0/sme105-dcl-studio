## Reference, not SME-105 verification

Source: https://github.com/doncreat0r/eeciv/blob/master/Diag324.c

Reference uses:

1. `Echo Module ID` 11-byte frame at 2400 baud 8N2.
2. If modeWaitID receives `01`, send `Go CART`
   `00 00 00 00 00 01 04 00 00 00 05`, still at 2400 8N2.
3. Enter CART mode at 9600 baud **8N1**, not 8N2 (reference br9600).

This is a protocol hypothesis for SME-105, not an ECU-specific capture.

## Prepared software

`firmware/dcl_cart_once/` and `scripts/cart_session_once.py`.
Firmware is not automatically uploaded. It never transmits on boot.
One explicit `START` attempts a bounded Echo-ID frame. It requires
**exact** 11-byte local echo + one `01`, without UART errors, before
sending exactly one bounded `Go CART` reference frame. Any mismatch
aborts and locks. After Go CART, the driver is disabled and UART
monitors at 9600 8N1 for 10 seconds. There is no periodic polling,
EEPROM/write/reset/clear command, or arbitrary raw send.

## Before connecting to ECU

Keep onboard `121` resistor unchanged. Verify external current limiting,
transient protection, pinout, ground, shrouded connectors, and that the
MAX487 `DE` has a 10k pull-down plus GPIO18 control (NOT hardwired GND).
The previous session does not certify electrical safety for the car.
Run ignition OFF while wiring, and KOEO during any test, engine stopped.

With the vehicle interface safely disconnected from the ECU, upload:

```bash
./.venv/bin/python -m platformio run \
  --project-dir firmware/dcl_cart_once \
  --target upload --upload-port /dev/ttyUSB0
```

USB-only preflight (no DCL transmission):

```bash
./.venv/bin/python scripts/cart_session_once.py
```

After a protected interface is verified, one explicit reference attempt:

```bash
./.venv/bin/python scripts/cart_session_once.py --send
```

Only if ready, manually type `START_CART_ONCE`. Transcript is saved to
`captures/CART_ONCE/`. Do **not** run the old binary capture script
simultaneously on the same serial port. Do not re-run --send if uncertain
whether a START reached the device.

## Interpret

- `ACK_REJECT`: no Go CART sent. Examine echo and serial errors.
- `ACK_CANDIDATE 01`: source is unverified; conditional branch accepted.
- `TX_FRAME GO_CART bytes=11 watchdog=OK`: ESP UART wrote 11 bytes only;
  it is not ECU confirmation.
- `CART_RX ... hex=`: candidate CART traffic, possibly local GoCART echo;
  inspect parity and timing; do not declare live PIDs yet.
- `CART_DONE bytes=0`: no UART bytes decoded after mode switch.
