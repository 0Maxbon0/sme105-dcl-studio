## Failed attempts and fixes

1. First direct-run scripts/sme105_direct_ap_setup.py failed with ModuleNotFoundError for scripts package. Fixed bootstrap for direct execution.
2. AP already broadcast correctly, RT5370 scanned ~95%, but first two **nmcli --ask** secret prompt attempts (plain pty slave, controlling tty) hung at **connecting (need authentication)**, timed out. This was a **host NetworkManager secret-agent interaction**, not evidence of RF/AP failure. Replaced with tightly validated D-Bus secret provisioning via system python3-dbus.
3. First system D-Bus helper erroneously unpacked one matched connection tuple as two values, causing ValueError. Fixed to index the single validated connection. NetworkManager connection then activated immediately; no password was placed in CLI argv.
4. Independent review identified stale AP_STOP callback generation risk, AP stopped but selection falsely saying starting, potential partial NVS PSK-write lockout on power failure, stale manual NM DNS/routes, profile autoconnect before it was hardened, and an interim unit-test fixture error. These were fixed and test-checked **before signed v9** was frozen/flashed. v8 remains uninstalled.
5. Earlier v7 router-based STA disappeared in the car; that original root cause is **still unknown**. Moving to the desk restored it. Direct AP reduces router/DHCP dependency, but cannot fix weak in-car 5V supply, RF shielding, resets, vibration or interference.

## How the host now reconnects automatically

NetworkManager connection profile **SME105-Direct-USB** is pinned to wlx1cbfce64dd94, autoconnect=yes, 10.77.13.2/24 static, no gateway/DNS/IPv6/default route. Initial setup over USB is scripts/sme105_direct_ap_setup.py (verifies status, USB-only secret provisioning and separated routes). Companion scripts/sme105_nm_usb_secret.py must run with **/usr/bin/python3 (python3-dbus)**, validates exact profile ID/SSID/interface/security and writes AP PSK through system D-Bus; never prints the password or inserts it into a command line. Existing TCP token file remains private and unchanged.
