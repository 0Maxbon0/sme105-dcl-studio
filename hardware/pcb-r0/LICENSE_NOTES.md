# KiCad library attribution

The footprints under `parts.pretty/` are derived from KiCad's official
footprint library shipped with Ubuntu package `kicad-footprints` 7.0.11.

KiCad libraries are licensed under Creative Commons Attribution Share-Alike
4.0 with the KiCad libraries exception. Their original library and license
information are available from:

https://gitlab.com/kicad/libraries/kicad-footprints
https://www.kicad.org/libraries/license/

These files were renamed from their upstream footprints to be self-contained
within a KiCad local library `SME105`; the pad geometry should be re-checked
against an exact orderable part before fabrication.

No license is asserted for vehicle-specific DCL protocol documents owned by
third parties, and no source firmware or private captures are included in
the board review bundle.
